# 壊れ方

**今の造りでも起きる壊れ方だけを集めてある。** 規則を変える前に読む。

二代ぶんの道具で実際に壊れたことの記録から、**平らな棚（作品フォルダを作らない・
シリーズ名を決めない）でも成り立つものだけ**を選んで、壊れ方の形ごとに並べ直した。
落としたのはシリーズ名を作る工程にしか当てはまらないもの（39 件を残し、28 件を落とした。
原本は `F:\Temp\_隔離\20260805 BookOrganizer一式` に在る）。

**読み方** — 直そうとしている場所と同じ形の穴が、この中に既に開いていないか探す。
どれも静かに壊れる類で、抜き取り検査では見つからなかったものばかり。

---

## 一 名前を当てにして壊れた

**ファイル名も題名も、いちばん弱い手掛かり。** 開けば分かることを名前で当てない。

### 1-1 語の境界を切らないと、途中に食い込む

宣伝物を見分ける語に `フェア`（書店フェア）を入れていた。

```
ソードアート・オンライン 3 フェアリィ・ダンス
    → 宣伝物と判定され、本篇の巻から外れかけた
```

後ろに片仮名が続かないことを条件にして直した。

### 1-2 書店名は作品名でもある

特典を見分ける語に書店名（とらのあな・ゲーマーズ・メロンブックス）を入れていた。
**『ゲーマーズ!』というライトノベルがある。**

```
ゲーマーズ!5 ゲーマーズと全滅ゲームオーバー
    本文 137,489 字（＝立派な本篇の一冊）  → 特典と判定された
```

書店名は「特典・限定」と近くに並んでいるときだけ数える。

### 1-3 言い方は数え上げられない

販売表記を落とす規則が `(?:電子|イラスト)特典付き` と書いてあり、実物は間に
`ＳＳ` が挟まっていた。

```
死亡エンドを回避した…らしい２【電子ＳＳ特典付き】
源                  死亡エンドを回避した…らしい2      → 別の題名として扱われた
```

中身を数え上げようとしたのが誤り。**末尾の語**で判定する。
ただし【】を無条件には落とせない — `…俺の【日記帳】を読んで…` のように
題名の一部のことがある。

**どれだけ効いたか** ある回の未決 4 件のうち 3 件がこれだった。

★ 今の `mori.strip_decor` はこの形。落とした結果が**完全一致したときだけ**
意味を持たせているので、外れても嘘の一致は生まれない。

### 1-4 名前が中身に勝ってはいけない

```
聖剣使いの禁呪詠唱＜ワールドブレイク＞22.epub
    1,004 頁 / 750 画像 / 2,716,416 字   ← 普通の巻の十数冊分
    遠端では「22 巻がある。題名も著者も一致」で確定していた
```

合本版だった。名前から巻号を読んで、中身の量を見ていなかった。

### 1-5 ファイル名と OPF の両方を見る

```
負けヒロインが多すぎる!.epub
    OPF の題名「『「負けヒロインが多すぎる!」いみぎむるARTWORKS』購入特典」
時々ボソッとロシア語でデレる隣のアーリャさん.epub
    OPF の題名「… ももこ画集」
```

ファイル名は本篇と同じで、OPF の題名にだけ画集と書いてあった。

★ さらにこれは**画集の**特典であって小説の特典ではない。

### 1-6 漫画は名前で見分けられない

```
転生王女と天才令嬢の魔法革命 1〜9
    各 2,535 字 / 画像 169 枚 / 169 頁   ← 漫画版。名前は本篇と区別が付かない
```

★ **画像の枚数で漫画を判じてはいけない。** ラノベにも挿絵がある。
最初の版は「画像 20 枚以上」で判じ、標本の 30% を誤判定した。
見るのは**本文の量**（漫画は本文がほぼ無い）。

### 1-7 巻ごとに改題する作品がある

```
生徒会の一存 碧陽学園生徒会議事録1   ← 前方一致する
生徒会の二心 碧陽学園生徒会議事録2   ← 一致しない
生徒会の三振 …   生徒会の四散 …
```

1 巻だけが残るので絞り込みは成功に見え、**残る 12 巻が黙って消える**。
〈物語〉シリーズも同型（傷物語・鬼物語 は各巻が別の題名）。

**残った数が源の巻数の半分に満たなければ、題名の照合を信用しない。**

### 1-8 漫画は入口で弾く

小説の棚の同定に漫画の条目を混ぜてはいけない。ある源にしか無い作品では
漫画の条目が「唯一の候補」になって自動採用される。
`明日ちゃんのセーラー服`（集英社）が実例で、16 巻がまるごと小説の棚に入っていた。
全数を洗ったら他に 3 作品出た。

★ 今はラノベの杜のレーベル名がこの門になる
（`ヤングガンガンコミックス` `角川コミックス・エース` …）。

---

### 1-9 ファイル名が一冊ずれている。**中身を読むまで分からない**

旧い整理の付けたファイル名は、**題名も巻号も日付も**別の巻のものであることがある。
同じ系列の中で一冊ずつずれていた例:

```
ファイル名                          本文の柱（＝中身が名乗る題名）
魔術師の杖①                        魔術師の杖 短編集①
魔術師の杖 短編集①                  魔術師の杖⑧
魔術師の杖⑧                        魔術師の杖⑨
最果てのパラディンⅢ〈上〉             最果てのパラディンⅢ〈下〉
最果てのパラディンⅢ〈下〉             最果てのパラディンⅣ
```

**手元に無い巻の分だけ、名前が前へずれる。**

★★ **これで九件を取り違えた。しかも道具は正しく止めていた。**
日付の幅（実測-23）が「杜の行と日付が合わない」と言って止めたのを、
`杜が別の行へ飛んだ` と読み違えて**名前の側を採った**のが誤り。
実際は逆で、杜が返した行が正しく、ファイル名が別の巻を指していた。

```
台帳（誤）                     実際（柱・奥付・杜が揃う）
86―エイティシックス―           86―エイティシックス― Alter.1     奥付 230410
安達としまむら２                安達としまむらSS2                奥付 241110
Unnamed Memory I              Unnamed Memory -after the end- VI  奥付 250517
ようこそ実力至上主義の教室へ 3年生編4  ようこそ実力至上主義の教室へ 3    奥付 160131
```

★ **証拠の強さは 柱 ＞ 奥付 ＞ OPF ＞ ファイル名。**
柱は本文と一緒に組まれるので一番ずれにくい。奥付は本の中に印刷されている。
OPF は出版社が別に書くので写し間違いが混じる。ファイル名は蔵書の側の都合。

★ **止まったものを通すときは、名前ではなく中身を見る。**
日付の幅が止めるのは「名前と源が食い違っている」ことだけで、
**どちらが正しいかは言っていない**。そこを名前の側に倒したのが間違いだった。

★ 見つけ方は `audit` の「奥付が印刷した発売日と台帳の発売日が離れているもの」。
二ヶ月以上離れていたら、まず中身を読む。

### 1-10 「同じ巻の二つ目の実体」は、**別の本**かもしれない

ファイル名が同じでも中身が違うことがある（1-9 の裏返し）。

```
[MF文庫J][…][260525] ようこそ実力至上主義の教室へ 3年生編4.epub  → 柱 ようこそ…へ3
[MF文庫J][…][260525] ようこそ実力至上主義の教室へ 3年生編4.epub  → 本文に 3年生編4
```

同じ名前の二冊を「同じ巻の写し」と読んで統合したが、**別の巻だった**。
`record --only` で切り離して立て直した。

★ 統合する前に、**二つの中身が同じことを確かめる**。名前が同じなのは
統合してよい理由にならない — 名前を付けたのは源ではなく、こちらだから。

## 二 揃え方が足りなくて壊れた

**当てる前に必ず幅を揃える。** そして揃え方の網羅は、すぐ漏れる。

### 2-1 全角と半角

合本版を見分ける規則が半角数字だけを見ていた。

```
［合本版］ふぁみまっ！ 全９巻 (GA文庫)   → 合本版と認められなかった
```

当てる入口を一か所に絞り、そこで NFKC を通す。

### 2-2 揃えるのが後だと間に合わない

1-3 の `【電子ＳＳ特典付き】` は、落とす処理が NFKC の**前**にあったので
全角の `ＳＳ` は幅も揃っていなかった。**順序が要る。**

### 2-3 落とす記号の一覧は漏れる

正規化で全角の `〈〉《》≪≫«»` は落としていたのに、半角の `<>` が残っていた。

```
<Infinite Dendrogram>-…-   と   〈Infinite Dendrogram〉-…-   → 別の本
```

★ 今の `norm()` も同じ形で漏れていた。NFKC は `～`(FF5E) を `~` にするが
`〜`(301C) は変えない。「嘆きの亡霊は引退したい 〜…〜 13」がそれで外れていた。

★ 逆に**揃えすぎてもいけない**。長音符 `ー` は日本語の字で、
半角にすると `コーヒー` が壊れる。

### 2-4 剥がしたものを戻さない

先頭タグを落とす関数が、日付だけを拾って `[日付] 題名` の形で返していた。
呼ぶ側がもう一度剥がす前提だったが、その剥がし役を消したとき日付が残った。

```
86―エイティシックス―  が  [240714] 86―エイティシックス―  として比較された
    → 全件外れた
```

### 2-5 数字の書き方は一通りではない

丸数字 `①②③`（NFKC でも数字にならない）、全角ローマ数字 `Ⅰ`（U+2160、ASCII の
`I` とは別字）、全角数字 `１`、小数巻 `4.5`、ローマ数字 `XXXVI`（20 までの辞書では足りない）。

★ ローマ数字として**読めてしまう綴り**に注意。`Lv.2` の `lv` を
L+V=**55** と読んで、24 巻の作品が 2 巻になったことがある。

### 2-6 拡張子は白名単で切る

最後の `.` で無条件に切ると
`シャーロック＋アカデミー Logic.5 不在探偵は不在です` の巻号が消える
（`Ep.2`、`life.10` も同様）。

かといって「拡張子らしい綴り」で判定すると、今度は `…教室へ 4.5` の `5` が
拡張子になり **4.5 巻が 4 巻に化ける**。

### 2-7 巻号は題名の中ほどにも末尾にも来る

```
主題と副題の間     異能学園の最強は平穏に潜む (2) ~規格外の怪物…~
副題の後ろ        水属性の魔法使い 第三部 東方諸国編7
分冊が巻号の直後   最果てのパラディンⅢ〈上〉 鉄錆の山の王
```

先頭からしか読まないと全部取り逃す。

### 2-8 1 巻の題名には巻号が書かれない

源によらず起きる（`六畳間の侵略者!?`、`義妹生活`）。
対処を忘れると **ほぼ全ての作品が「1 巻が無い」** と報告される。
実際、ある回の質問 30 件のうち 26 件がこの誤報だった。

**これまで五つの経路で踏んでいる。** 新しい源を足すたびに確かめること。

## 三 強い証拠が弱い証拠に負けた

### 3-1 文書に「弱い」と書くだけでは守られない

1-2 で `ゲーマーズ!5` が特典と判定されたとき、**その本文が 137,489 字あることは
同じ関数の中で既に計算されていた。**

```
種類の判定   結果 特典  理由「特典を名乗っている」   ← 名前が勝った
中身        本篇の一冊ぶんの分量か  True            ← 計算済み・未使用
```

規則には「名前はいちばん弱い証拠」と書いてあったが、
**コードのどこにも「弱い」を表す仕組みが無かった。**
弱いはずの証拠が強い証拠と衝突したとき、負ける経路が存在しなかった。

**直した（一度目・誤り）** 「中身が一冊分あれば名前を捨てる」という閾値と
優先順位をコードに書いた。→ 同じ病だった。作った規則は予想しない組み合わせで
必ず間違える。

**直した（二度目）** 示唆を並べるだけにして、食い違えば決めずに人へ回す。

★ **この一件が、今の造り（判断は AI・コードは確定した操作だけ）の理由。**

### 3-2 遠端どうしの照合は、手元の本を見ていない

「題名が完全一致し著者も一致」だけで確定していた。それは**遠端どうしの照合**
であって、手元の本が本当にそれかは確かめていない。

奥付（印刷された事実）と本文の量を突き合わせる段を足した。

### 3-3 「不明」を「一致」に繰り上げない

片方に値が無いのは「確かめられなかった」であって「合っていた」ではない。
BookWalker は著者を載せないことが多い。これを一致に丸めると別人の本が通る。

### 3-4 一致の数で矛盾を押し切らない

数は弱い証拠を束ねているだけ。題名・レーベル・発売日が揃っていても、
巻号が違えば別の巻。

### 3-5 権威を一つに決めると、その穴が事実に昇格する

一時「源が食い違ったら BookWalker を正とする」という序列を置いたが、
**同じ日のうちに取り下げた。** BookWalker はシリーズ頁の巻を取りこぼす:

```
シャーロック＋アカデミー   1 巻としてしか返らない（手元に 4 冊）
シャインポスト             1 巻としてしか返らない（手元に 3 冊）
```

ここを「正」に据えると、**取りこぼした巻が「存在しない巻」に昇格する**。
手元の 3 冊が「余分な本」になり、退避の対象にすらなりうる。

★ この取りこぼし自体は後で直った。だが**直ったから序列を置いてよい、
という話にはならない** — 次の穴は別の場所に開く。

★ 今の造りでは「項目ごとに一次の源を決め、他は検めに使う」がこれにあたる。
一次を決めるのは項目単位であって、源の序列ではない。

### 3-6 「候補が一つ」は安全の証明にならない

本篇が手元に無いと、外伝が「唯一の候補」になり本篇の名前に書き換えられる。
逆向きもある。自動でよいのは**記号の違いだけ**のとき。語の増減は人に回す。

## 四 段と段のあいだで結論が落ちた

### 4-1 前の段の結論が、次の段に渡っていなかった

同定は正しく決めていたのに、**まったく別の作品の名前**が付いた件が四つ。

```
逆転世界の寵愛者        → 『貞操逆転世界の童貞辺境領主騎士』
初恋のお姉さんを今度養う  → 『冷遇されるお飾り王妃…初恋の王子様に攫われました!』
```

同定は「その源は矛盾（または不明）」と算出していた。だが名づけの側は
各源の候補の `[0]` を無条件に採っていた。

★ 一件は**否定する材料が一つも無いので「不明」**になっていた。
それを採ったために別作品の名前が付いた。**不明も落とす**のが要点。

★ 併せて、矛盾・不明の源の答えは台帳にも書かない。あとで発売日やレーベルとして
読まれると、別の作品の書誌が混ざる。

### 4-2 材料を集める者に、点数を付けさせない

採集が「源に問う」と「どれか決める」を一つでやっていた。すると
**たまたま引いた源が、そのまま判断に使った源になる。**
説明文には「RanobeDB しか見ていない」と書いてあったが、判断もそこで
下していたので誰も気づけなかった。実測で散巻 41 件のうち 9 件がこれだけ。

分けた。記録には**明確な「無い」も残す** —
「問うたが無かった」と「そもそも問うていない」は別のことなので。

★ 判据は緩めない。変えてよいのは**問い先の数**だけ。
厳しさと、どこに問うかは別のこと。

### 4-3 id だけを伝えると、源を当て推量される

台帳の鍵は **(源, id) の対**。id は源をまたいで共有されない。

```
ranobedb:13986  親ガチャ失敗したけど…（小説・2 巻）
bangumi:13986   マインド・ゲーム オリジナル・サウンドトラック（0 巻）
```

`作品は 13986 と確定` としか書いていなかったため、後から裁定する側が源を
当て推量し、**小説をサウンドトラックに紐づけた**。

★ 今の台帳が `作品: rdb:6547` の形なのはこれが理由。

### 4-4 「何もしなかった」は「何かした」と同じくらい見えていること

`if v is None: continue` という一行があった。台帳では作品が決まっているのに、
その巻が源の巻一覧に無いファイルは、**移されず・報告されず・件数にも出ない**。
plan は「1 ops」と言い、実測 22 冊が置き場に取り残されたままだった。

**飛ばすなら、飛ばしたと言う。**

★ 今の `plan` の「置けなかった」がこの受け皿。

## 五 同じ規則が二か所にあり、片方だけ直した

**いつもの形。** 新しい経路を足すときは、既にある経路の注意書きを全部読む。

### 5-1 判定が二か所に分かれる

欠巻の印を「0 バイトかどうか」で見分けていたが、中身のある印が 26 件あった。
しかも判定条件が**二か所に別々に書かれ**、片方だけ直して食い違った。

★ **今回も再現した。** 移行で退けた印 1,128 件のうち 24 件に中身があり、
道から抽出する処理だけを直したので、最初は 24 件しか読めなかった。

### 5-2 受け皿が片方のアダプタにしか無い

「1 巻には巻号が書かれない」の受け皿が一方には在り、他方には無かった。
別の件では「状態フォルダを除外する」が片方にだけ入っていた。

**受け皿は一つにまとめる。増やさない。**

### 5-3 坑を塞ぐ補修が、別の坑を開け直す

候補の選び直しを足したとき、**最初に通したはずの検査を省いていた**ため、
別の門が開いた。

**一方の坑を塞ぐ道を足したら、その道でもう一方の門をくぐったか確かめる。**
補修の中で候補を選び直すときは、最初に通したのと同じ門を全部通す。

★ 今回、`apply` に並べ替えを足したときにこの形をやりかけた
（門①が計画の中の先後を知らない）。

### 5-5 派生物を作り直す手を、それを狂わせる手と一緒に置かなかった

欠巻の標は台帳から毎回引き直す派生物なのに、**巻を記録する周に引き直していなかった。**
結果、既に手に入れた巻の場所に標が立ったままになる。

```
[GAノベル][進行諸島][風花風花][180511] 転生賢者の異世界ライフ….txt   ← 標（724 バイト）
[GAノベル][進行諸島][風花風花][180515] 転生賢者の異世界ライフ….epub  ← 本体（16.5 MB）
```

日付が四日ずれているのは、標が RanobeDB の発売日を、本体が杜の発売日を継ぐから。
**同じ一巻が二つ並んで見える。** 引き直したら 69 本が下りた。

★ 見つけたのは人。道具はどれも気付いていない — 標は台帳の外に在るので、
  `audit` が見ている台帳と実体の照合には掛からない。

**どう直したか** 一周の締めに `gaps --apply` を入れた。
**台帳を動かす手と、派生物を引き直す手は、必ず同じ一周に置く。**

### 5-6 同じ台帳へ書く周を並行して回し、追記が行の途中で割れた

速さのために周を並行させたら、`var/works.jsonl` の末尾に `}}` という
**二文字の欠片**が出来た。追記が行の途中で割れたもの。

失った記録は無い（作品 687 件は全部揃い、巻が指す作品も一つも欠けていない）。
壊れたのは、記録ではなく **記録の書きかけの尻尾** だった。

**それでも被害は大きかった。**

```
検め   → JSONDecodeError で丸ごと落ちた
配置   → 同上
標     → 同上
```

一行が読めないだけで、**台帳を読む道具が全部止まった**。しかも止まった場所が
「検め」の中なので、その周の検めが飛んだことは締めの一行を見ないと分からない。

**どう直したか（三つ）**

1. `_read` を、読めない行を**飛ばして、飛ばしたと言う**形に変えた。
   台帳は一行ずつが独立した記録なのだから、壊れた一行の被害は
   その一行に留めるべきだった（四章）。
2. `_append` を一行ごとに flush する形に変えた。
3. 欠片は落としたが、**落とす前の写しを隔離に置いた**（`隔離/台帳の破れ/`）。
   台帳に触ったという事実そのものを残すため。

★ **同じ台帳へ書く周を、二つ同時に回さない。** 速さのために並行させたが、
  止まった周の取り戻しに掛かった時間の方が長かった。

### 5-7 同数のときの決め方を決めておらず、派生物が毎周ちがう名前になった

欠巻の標のタグは手元の巻から継ぐ。その「一番多いもの」を
`max(set(vals), key=vals.count)` で採っていた。

**同数のときの決め方が無い。** 勝者は set の巡り順で決まり、
文字列のハッシュは走るたびに変わる。結果:

```
台帳は一行も動いていないのに、毎周 8〜19 本の標が隔離へ落ち、
別の名前で立て直される
```

同じ台帳から `build()` を二度呼ぶだけで、下ろす数が 8 と 12 に割れた。

**どう見つかったか** 「巻が増えていないのに標が動き続けている」という
締めの数字の食い違い。**一本ずつ見ていたら気付けない。**

**どう直したか** 同数なら「巻号の若い巻のもの」を採る、と決めた。
作品の顔はふつう一巻にある。直したあと、三度走らせて名前の一覧が
同じ指紋になることを確かめた。

★ **派生物は、同じ入力から同じ出力が出ることを確かめる。**
  数が合っていても中身が入れ替わっていることがある（今回は総数 1116 が
  三度とも同じで、**名前だけが違っていた**）。

### 5-8 源の「順」と、表紙に印刷された巻号は、別のもの

`魔弾の王と凍漣の雪姫` で、同じ作品に巻号 2 の巻が二つ出来た。
RanobeDB がこの作品の 190125 発売の一巻を**持っていない**ので、
190524 以降の `順` が一つずつ手前にずれていた。

杜を ISBN で引けば一意に決まる — `9784086313063` は「３」。
**ISBN は一冊を名指しする。順は名指ししない。**

### そのあと、危うく 201 件を壊すところだった

「題名の数字と巻号が食い違うもの」を全台帳で数えたら **201 件**あった。
直そうとする前に中身を見たら、**大半は誤りではなかった**:

```
「ようこそ実力至上主義の教室へ 3年生編３」  巻号=32  ← 作品の中での位次
「月が導く異世界道中8.5」                  巻号=9   ← 8.5 も一つと数える
「冴えない彼女の育てかた Girls Side 3」     巻号=16  ← 外伝も並びに入る
```

`巻号` は **RanobeDB の順＝作品の中での位置**であって、表紙の数字ではない。
二つは設計として別物で、食い違うのが普通。

★ **201 件という数字そのものが罠だった。** 数が多いことは、
  同じ誤りが広がっている証拠にも、**その物差しが間違っている証拠**にもなる。
  数えたあと必ず**中身を見る**（五章 5-4 は「数えてから直せ」だが、
  数えた**あとに見る**まで含めて一つの手順）。

★ 本当の合図は数ではなく、**台帳の中での矛盾** — 検めの
  「同じ作品の同じ巻号が二つ」。これは 5 組しか挙げず、5 組とも本物だった。
  **外の物差しと比べるより、内側の食い違いを見るほうが当たる。**

### 5-9 見る形を一つに決めていて、置き場の半分が目に入らなかった

「もう処理し終えたか」を確かめたら、置き場 3,936 ファイルのうち
**道具が見ていたのは 259 件だけ**だった。`BOOK_EXT` に `.zip` が無いので、
書庫はファイル数にすら数えられていなかった。開けたら:

```
[石踏一榮] ハイスクールD×D 01-25.zip        中に epub 25 冊
[海空りく] 落第騎士の英雄譚 01-19+零.zip     中に epub 20 冊
妹さえいればいい。1-14 HQ.zip               中に epub 14 冊
…                          合わせて **104 冊が一度も調べられていなかった**
```

「材料 0 件」は「置き場が空」ではなく「**道具が見る形のものが無い**」だった。
その二つを同じ言葉で報告していたので、終わったと読んでしまった。

★ **数え上げたものと、実際に在るものを突き合わせる。** 「0 件」を見たら
  「何を 0 と数えたのか」を確かめる。

### 5-10 標を見分ける形が二通りあり、片方しか見ていなかった

置き場の `_用済みの欠巻マーカー` 154 枚が仕分けを素通りした。
中身が `これは欠巻の標です` で始まるかどうかで見分けていたが、
**前の整理は 0 バイトの `.txt` を標にしていた**ので、一枚も当たらない。

これは 5-1 とまったく同じ形（標の見分け方が二か所にあり、片方だけ直した）。
**同じ章に既に書いてあることを、また踏んだ。**

### 5-4 一件の指摘は、同じ形が何件あるかを測ってから直す

前の道具で 18 件の差し戻しを追ったとき、指摘は 1 件でも同種は
**8 件・15 件・26 件・1192 件**あった。**必ず数えてから直す。**

そして原因の形はほぼ二つに集約される（この章と、四章）。

## 六 台帳と時間

### 6-1 弱い規則で書かれた行が、規則を外したあとも残る

早い時期に「無番号の巻が一つだけならそれを 1 巻とみなす」という弱い規則があった。
のちに外したが、**それで書かれた行は残った。** 見た目は他の行と区別が付かない。

```
劇場版 STEINS;GATE 下   → 1 巻として台帳に入っていた
影響を調べた 12 件のうち、1 件が本当に間違っていた
```

**どう見つかったか** 別件の調査のついで。**探さなければ出てこなかった。**

★ 台帳は追記のみなので、この性質は今も同じ。規則を変えたら、
その規則の下で書かれた行が残っていることを思い出すこと。

### 6-2 決め終わったものを毎周決め直す

台帳に着いたファイルを除外していなかったため、毎周同じものを決め直していた。
「新しい同定が出なくなるまで」という終わり方が永久に来ない。

★ 今の `settled_fingerprints()` がこれ。

### 6-3 鍵はファイル指紋。フォルダ名にしない

フォルダ名は整理の途中で変わる。以前は「状態/フォルダ名」を鍵にしていたため、
整理が一歩進むたびに台帳が丸ごと無効になっていた。

### 6-4 数は一か所にしか置かない

本文の量の実測値を、規則の条文に直接書いていた。測り直したときに全部を直せず、
四か所が食い違った。

```
文書の記述                          実際（全量 2,862 冊）
本篇 68,306 〜 288,534               23,608 〜 2,716,416
比 0.5 以上 2,292 冊                 2,462 冊
```

`68,306` は **60 冊の標本の最小値**を、全体の値として書いたもの。

★ これが `2-実測.md` の存在理由。測った日と標本の数を必ず添える。
**掛け算で数を作らない。**

### 6-5 一つの巻が二つの巻ID を持つ

鍵はファイル指紋なので（6-3）、**同じ巻の別の実体は別の材料として上がる**。
一つの巻を二つの批で拾うと、二つの巻ID が立つ。

```
V000183  ようこそ実力至上主義の教室へ 3年生編4   14.6 MB  （批 6 で拾い、棚へ）
V000344  ようこそ実力至上主義の教室へ 3年生編4   23.9 MB  （批 10 で拾い、別に立つ）
```

同じ巻に実体が二つ在るのは想定どおりで、採用の規則（7-4）も隔離の置き場もある。
だがそれは**一つの巻ID の中に二つの実体が在るとき**の話で、
巻ID そのものが二つに割れると、その仕掛けは何もしない。棚には同じ本が二冊並ぶ。

**対処は入口と出口で対。**
入口 — 台帳に入れる前に **ISBN が既に台帳にあるか**を見て、あれば人へ回す。
出口 — `record --retire-into` で畳む。台帳は追記のみなので**行は消さない**。
実体を一つも持たない行を足すと、`plan` がその巻を飛ばす。

★ 気づけたのは `record` が「同じ ISBN が V000183 にもある」と**言った**から。
黙って通していたら棚に二冊並び、次に気づくのは棚を眺めたときだった。
**確定の層は判断しないが、気づいたことは言う。**

## 七 動かすときに壊れた

### 7-1 移動で書誌を落とさない

源によっては書誌をまったく持たない。そのまま名前を組むと、
**元の名前に書いてあった書誌が移動で消える。**

```
[HJ文庫][葵依幸][Enji] 勇者殺しの花嫁 III- 神殺しの少女  →  勇者殺しの花嫁
[電撃の新文芸][結城涼][なかむら]  →  [KADOKAWA][結城涼]
```

一件ずつ見ると小さいので、8 件が誰にも咎められず通った。

**対処は二つで対。** 組む側が「元の方がタグが多ければ元を採る」。
そのうえで**門②がタグの減る移動を実行の前で止める**。

★ 枠の中身が入れ替わるだけは通す。どちらが正しいかは判断であって、
確定の層の仕事ではない。**日付も同じ** — 入れ替わるのは通し、消えるのは止める。

★★ **この一行が守られていなかった。** 門②は値の集合を引き算していたので、
入れ替わりを片端から「減った」と読んだ。日付だけを例外にして凌いでいたが、
例外は次々に出てきた:

```
古河 樹 → 古河樹        源によって姓名の間を空ける（実測-25）
B6判  → KADOKAWA      判型がレーベル欄に入っている行がある（実測-26）
```

例外を一つずつ足していく限り、そのたびに正しい付け直しが止まる日が来る。
**見るのは数**。値の取り違えはここでは捕まえない — それは `audit` の仕事で、
実際 `魔女と傭兵6上` を捕まえたのも audit の二つの突き合わせだった。

★ 一般に、**守り手を守るべきものより広く書くと、正しい仕事の方が先に止まる。**
門②が守っているのは「台帳のタグが埋まっていない」ことだけで、
それは値ではなく**数**に現れる。

### 7-2 フォルダは中身が決まってから作る

置く先を決める**前に** mkdir を積んでいた。割り当てが全部空振りすると、
**空のフォルダだけが残った。**

★ 今回も踏んだ。`plan` が隔離先の path を組むだけで mkdir していた
（計画しただけでフォルダが生える）。

### 7-3 「同じ巻」でも中身が違うことがある

巻号が読めないファイルがどれも 1 巻に寄せられたため、
`劇場版…デジャヴ 上` と `下`、本篇と `Secret File` が同じ巻として束ねられた。

**退けるのは戻せない**（今の造りでは隔離へ移すので戻せるが、気づかなければ同じ）。
名前が一致するときだけ別版とみなす。

### 7-4 採用の選び方

同じ巻に実体が複数あるとき、上から順に、決まった時点で止める。

```
① epub を優先する
② どちらも epub なら、ファイルサイズの大きい方
③ サイズも同じなら、日付の新しい方
```

残りは**消さずに隔離へ移す**。日付を最後にするのは、再配布のたびに新しくなり
単独では品質の目安にならないため。

### 7-5 特典は本篇の巻ではない

`【電子特典付き】` が付いているのは**特典付きの本篇の巻**であって特典ではない。
一方、ファイル名に何も書かれていなくても OPF に `購入特典SS` とあれば特典。
ファイル名だけで判断すると、**特典が本篇の巻を押しのける。**

## 八 測り方が間違っていた

**代理の指標を成果と読まない。**

### 8-1 「問いが減った」は広げた証拠にならない

「人への問いが減った＝機械が決めるようになった」と読んでいた。
だが問いが減る理由は三つあり、字面では見分けられない:

```
① 機械が決めるようになった（＝広げた）
② 人が答えた
③ 問いそのものを捨てた
```

③ で誤報したことがある。**誤報を続けると警告そのものが読み飛ばされる。**

### 8-2 台帳の行数を「機械が決めた数」と読まない

そこには**本の裁定（2,788 行）と印の控え（1,192 行）が混ざっていた**。
印の登録は行き先を決める判断ではなく、道具が自分の出力を控えているだけ。

### 8-3 「発売日付きファイルの割合」は完備性ではない

それは命名が済んだことしか意味しない。何が欠けているかは、
源の全巻一覧と突き合わせないと分からない。

### 8-4 毎バッチ検める

置いた結果を構造の観点から精査する。別の場所を直したときに入り込んだ不具合を、
これが全部拾ってきた。**人の抜き取り検査では見つからない類ばかり。**

### 8-5 「承知」で黙らせたものが、探せば見つかるものだった

`--noted`（承知）は **`audit` の出力を下げる印**として作った。
「絵の無い一般小説」「どちらの源も持っていない児童書」のように
**直しようが無い**ものを毎周並べないための仕掛けだった。

ところが `作品を持たない巻` に片端から承知を付けたせいで、
**探せば見つかるもの 47 冊が未分類に埋もれた**。人に指摘されるまで気づかなかった。

```
作品なし 120 冊 → 実際に補えたもの 47 冊
   涼宮ハルヒ 8 冊 / 生徒会シリーズ 5 冊 / 魔弾の王 3 冊 / 世界の終わりの世界録 3 冊 …
```

★★ **承知は「もう探さない」ではない。** 補う道具（`fill_work`）が承知を見て
飛ばしていたのが誤り。**印は報告を下げるだけで、やり直しは止めない。**

★ 承知を付けるのは「**なぜ直せないか**を一行で書けるとき」だけにする。
「探したが見つからなかった」は理由ではない — 探し方が足りないかもしれない。

★ 補えなかった 47 冊の内訳（＝探し方の穴）:

```
RanobeDB が検索するのは**作品名**で、巻の題名ではない
    「涼宮ハルヒの憂鬱」→ 0 件 / 「涼宮ハルヒ」→ 当たる
巻ごとに題名が変わる作品は、巻の題名をどう短くしても作品名にならない
    生徒会の一存／二心／三振… → 台帳の兄弟巻から候補を出し、RDB で確かめる
norm が長音符 ー を - に直すので、読みの括弧が仮名だけの判定から外れる
    <アンコール> → <アンコ-ル> で読みと認められていなかった
sub（.5 の巻・番外）を作品 id の継ぎ先から外していた
