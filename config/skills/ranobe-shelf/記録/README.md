# 記録の使い方

- [1-壊れ方.md](1-壊れ方.md)：書誌の取り違え、版の比較、実体保全に必要な注意点。
- [2-実測.md](2-実測.md)：再利用できる検証方法と確認すべき性質。

本機での処理件数、パス、批次、実行結果、再開条件は `local-run.md` に記す。同ファイルはGit対象外。継続作業時に存在すれば読み、スキルの配布物には含めない。

現在の手順は [SKILL.md](../SKILL.md) を正とする。過去の批次、機器固有パス、欠巻一覧、旧状態分類の説明は現行の指示に含めない。過去原文はスキル外の作業アーカイブに保存し、台帳と取消控えはそのまま残す。
