## 1-壊れ方.md の使い方

二代ぶんの道具で壊れたことのうち、**平らな棚（作品フォルダを作らない・
シリーズ名を決めない）でも成り立つものだけ**を選んである。
シリーズ名を作る工程にしか当てはまらない 28 件は落とした。

章立ては壊れ方の形。**直そうとしている場所と同じ章を先に読む。**

```
一 名前を当てにして壊れた       六 台帳と時間
二 揃え方が足りなくて壊れた      七 動かすときに壊れた
三 強い証拠が弱い証拠に負けた     八 測り方が間違っていた
四 段と段のあいだで結論が落ちた
五 同じ規則が二か所にあり、片方だけ直した
```

とくに**五章と四章**は、原因の形がほぼここに集約される。一件の指摘が来たら、
まずこの二つを疑って**同種が何件あるか数える**。前の道具では指摘 1 件に対して
同種が 8 件・15 件・26 件・1192 件あった。

## 2-実測.md の使い方

**「2,862 冊 × 86% = 2,462 件」のような数を書いた事故が三度ある**
（うち一度はこの記録を組み直している最中）。測っていない数は書かない。
測るなら測って、ここに足す — 測った日・何を測ったか・標本の数を添えて。
